## 2. USB 拓扑（lsusb 实测）

```
Bus 001 Device 002: 1c4f:0048  SiGma Micro USB Mouse（键鼠）
Bus 003 Device 002: 1a86:8091  QinHeng Electronics USB HUB（沁恒 CH33x 系）
Bus 003 Device 003: 303a:1001  Espressif USB JTAG/serial debug unit  ← ESP32-S3 LED 板
```

- **ESP32-S3 已枚举**：303a:1001（USB-Serial-JTAG 外设，即之前 ESP32 LED 项目 v1.0 固件的硬件 CDC 口），节点 **/dev/ttyACM0**（root:plugdev，带 ACL，<PI-USER> 在 plugdev 组可直接读写）
- ESP32-S3 挂在 **沁恒 USB HUB（1a86:8091）** 之下
- **uhubctl 未安装**；CH33x 系 hub 通常**不支持 per-port 断电** → 「USB 功控（断电重上电）」动作大概率做不了，规格中标记为**待验证/降级**（用串口 BOOT/RST 复位替代）

## 4. 对规格的影响（对应 OQ-1/OQ-6/OQ-4）

1. **OQ-1 设备清单**：一期实机设备 = **ESP32-S3 RGB LED 板**（USB 串口 /dev/ttyACM0）；动作建议：L0 读状态/读串口、L1 LED 颜色与闪烁模式控制、L2 复位进下载模式（esptool 类）。**网络类设备暂无实机**，矩阵预留行。
2. **OQ-6 硬件**：CM5 Lite 4GB——跑本地小模型偏紧，支持「一期纯本地规则」决策；USB 功控受 hub 硬件限制，降级处理。
3. **OQ-4 安全**：主机在局域网、免密 sudo——网关安全设计要按「最小权限」落实（磁盘缓存已于 10-24 清理，现 82%，装依赖空间充足）。
4. 闭环场景（OQ-2）候选：**断 WAN/网络异常 → 本地联动控制 ESP32-S3 LED 呈现状态码 → 校验**，一期不涉及真实网络设备亦可验收 AC-2。
